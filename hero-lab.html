Color correction:
reimagined for storytellers.

Adobe Premiere’s new Color Mode is a breakthrough, making color correction accessible and creative for editors who’ve always seen it as too technical.

See Color Mode in action: Watch the official Adobe film →

For decades, color correction belonged to specialists. Editors felt it was too technical, too intimidating. It was a world apart from the creative flow of storytelling. Color Mode changes everything.

Introduced in beta at Post|Production World, this new mode brings intuitive, powerful color grading directly into Premiere. Day two puts AI to work across the post workflow — taught live, like every session, by the Adobe team and Community Experts.

“Color is the ultimate storytelling tool.
For the first time, editors don’t need to be colorists to use it that way.”

— Adobe Color Mode beta user
